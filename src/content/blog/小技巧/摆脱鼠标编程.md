## 编辑与运行

- **Ctrl + Alt + L：**代码快速自动缩进整理
- **Ctrl + Shift + F10：**快速运行程序
- **Ctrl + Shift + ↑↓：**快速移动当前行代码到另一行
- **Ctrl + Shift + ←→：**快速选中代码
- **Ctrl + c/v：**复制粘贴
- **Ctrl + O：**快速实现该方法
- **Ctrl + Z：**撤销
## 代码导航与快速生成

- **Ctrl + F12：**查看当前类的所有方法
- **Ctrl + W：**选中你所想选的内容
- **Ctrl + /：**快速注释
- **Ctrl + F:**查找文本
- **Ctrl + F2：**停止程序
- Ctrl + 左键：添加输入光标
- **Alt + Enter：**光标选中报红位置，然后可以快速处理问题
- **Alt + Enter：**快速补全代码
- **Alt + Insert：**快速调用构造函数、toString、equals、get、set等等
## Windows 操作

- **Alt + F4：**快速关闭当前程序
- **Window + L：**快速锁屏
- **Window + E：**快速打开计算机
- **Window + D：**快速回到桌面
